# Baba — sorteio de times

Aplicativo simples para registrar atletas por ordem de chegada e sortear times com cinco jogadores.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Executar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

O sorteio usa todos os times completos possíveis. Se sobrarem atletas que não completam outro time de cinco, eles aparecem na reserva.
